# 🏠 Home Service Provider

A web-based home service booking application that allows users to explore and book home services through an easy-to-use interface.

## 🚀 Features

- User Registration and Login
- User Profile Management
- Home Service Booking
- Service Information
- Form Validation
- Password Encryption
- MySQL Database Integration
- Flask-based Backend
- Responsive Web Interface

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap

### Backend
- Python
- Flask

### Database
- MySQL

### Other
- Git & GitHub
